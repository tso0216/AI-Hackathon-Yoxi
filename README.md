# Demo

電腦網頁以手機畫面呈現，左側切換情境；手機直接開則是全螢幕。

## 快速使用

```bash
npm ci
npm run dev
```

開啟 http://localhost:5173

註：狀態存在瀏覽器 `localStorage`，左下「重設 Demo」可以清掉。

## 體驗流程

依序點左側情境：

| # | 情境 | 試試看 |
|---|---|---|
| 1 | 出門前 | 出門卡讀今天的行事曆，每個行程都說要不要叫車；按「不用」回饋；打開小黃經驗 +1 |
| 2 | 行程前 | 鎖屏跳出 yoxi 通知，在通知上按「預約 13:25」→ 小黃拿到小雨衣 |
| 3 | 一句話預約 | 今天頁的「跟小黃說要去哪…」：點建議句送出，小黃反問「9 點到還是出發」，選完出現確認卡，按了才預約 |
| 4 | 車上投稿 | 行程中拍窗外；照片綁定手機＋車輛 GPS，AI 選題（亮度、線索、去識別、定位）通過後投稿，經驗 +3；不在車上時不能拍 |
| 5 | 每天一題 | 今天頁的題目：4 個相近的地名選項；猜對連對 7 天、解鎖成就，看各選項選擇率，一鍵叫車過去 |
| 6 | 固定行程 | 前一晚鎖屏問「明天週四 07:40 照常去台北車站嗎？」；點通知看每條規律的信心度與近 4 週紀錄，預約或按「這週不用」 |
| 7 | 榮譽榜 | 你的照片成了題目：1,284 人猜、只有 295 人猜對，封號「迷霧製造者」；本月榮譽榜 |
| 8 | 小黃 | 經驗與成長階段、成就、配件、本月乘車金進度 |

叫車機率、等車時間、天氣、行事曆、猜題人數皆為模擬資料，不會真的派車。題目照片為 Unsplash 示意圖。

## 測試

```bash
npx playwright test         # 瀏覽器流程（需先 npm run dev）
```
